🧭 User flow

Love Run (4–5 min)
→ 10-axis behavior scoring
→ Big Five inference
→ Dating type card
→ Matching (type + similarity)
→ Guided first chat (3 turns)
→ Free DM unlock
→ Optional minigame

🧠 Core idea

  • Not a dating game — a matching platform concept
  • Roguelike run is for fun + data collection
  • Conversation is the main UX, minigames are optional

📊 Behavior axes (10)

cooperation leadership emotional_depth pace humor risk contact_frequency affection jealousy planning

🧬 Big Five

openness conscientiousness extraversion agreeableness neuroticism

Big Five is stabilized via cumulative aggregation.

🎯 Matching formula

match_score =
0.4 * behavior_score +
0.3 * big5_score +
0.2 * cluster_score +
0.1 * activity_score

🔒 Safety

  • DM filtering
  • Report / block (1 tap)
  • Abnormal behavior detection
  • Regeneration loop for unsafe content
