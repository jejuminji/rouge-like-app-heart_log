Love Log

Love Log는 단순 연애 게임이 아니라,
성향 기반 매칭(Big Five)과 대화 중심 UX를 결합한 실전 데이팅 플랫폼 컨셉 프로젝트입니다.

🧭 전체 사용자 플로우

Love Run (4~5분)
→ 행동 10축 계산
→ Big Five 추론
→ 연애 유형 카드 생성
→ 유형 + Big Five 기반 매칭
→ 가이드형 첫 대화 (3턴)
→ 자유 DM 해금
→ (선택) 함께 미니게임 / 대화 지속

“게임은 옵션, 대화는 본질” 구조를 유지합니다.

🧠 서비스 정체성

  • 게임 앱이 아니라 성향 기반 실전 매칭 플랫폼
  • 심리테스트가 아니라 행동 기반 성향 추론 시스템
  • 핵심은 “재미 + 데이터 수집 + 관계 가속”

로그라이크 런은 차별화 요소, Big Five는 알고리즘 핵심, 대화는 UX 본질입니다.

📊 행동 10축 (Run 기반)

짧은 런 플레이에서 유저의 반응을 수집하여, 단기 행동 성향을 추정합니다.

cooperation leadership emotional_depth pace humor risk contact_frequency affection jealousy planning

🧬 Big Five (장기 안정성)

Big Five는 누적 기반으로 안정화하며, 장기 관계 적합성 판단의 핵심 지표로 사용합니다.

Openness Conscientiousness Extraversion Agreeableness Neuroticism

런 결과는 과신하지 않고, 누적 데이터와 혼합하여 안정성을 확보합니다.

🎯 매칭 알고리즘 (4-Step)

  1. 유형 기반 1차 필터 (동일/보완/충돌 제외)
  2. Big Five 궁합 점수 (가중 유사도)
  3. 행동 벡터 유사도 (cosine)
  4. 최종 점수 합성 (가중 합 + 다양성 보정)

match_score =
0.4 * behavior_score +
0.3 * big5_score +
0.2 * cluster_score +
0.1 * activity_score

💬 대화 중심 UX

  • 첫 대화는 3턴 가이드형 템플릿으로 어색함 제거
  • 주제 카드 + 선택형 답변으로 진입 장벽 낮춤
  • 이후 자유 DM 해금

안전성과 리스크를 줄이기 위해, “초반 대화 UX”를 최우선으로 설계합니다.

🎮 미니게임은 ‘선택 기능’

미니게임은 매칭 점수를 뒤집지 않습니다.
대신 궁합 신뢰도(confidence_level)를 올리는 “관계 가속 장치” 역할만 합니다.

역할

효과

원칙
대화 중심 유지

🔒 안전 / 신뢰 설계

  • 가이드형 대화로 초기 리스크 감소
  • DM 필터링 + 신고/차단 1탭 제공
  • 이상 행동 탐지 시스템 구축
  • 금칙어 정책 + 재생성 루프 설계

“재미”보다 “안전”이 우선인 구조를 목표로 합니다.

🧩 AI 모듈 구성 (업무 분장)

Love Log는 아래 3개 AI 모듈로 분리 설계되어 있습니다.

  • 시나리오 이벤트 생성 (스키마 + 프롬프트 + JSON Structured Output)
  • Traits/매칭 엔진 (15축 누적 + 유형 카드 + 코사인 유사도)
  • 대화/게임/안전 (상태 머신 + 미니게임 + 안전 시스템)

이 구조는 “확장 가능한 팀 개발”을 염두에 둔 설계입니다.
